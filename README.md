# Aether Studio v1.0.0

Free, self-hosted app development studio. Build apps, SDKs, and fix projects automatically.

## Quick Start

1. Install Python 3.10+ from python.org
2. Double-click `install.bat`
3. Double-click "Aether Studio" on your desktop
4. Open http://127.0.0.1:5200

## Features

- App Builder (12 languages: Python, JS, TS, Go, Flutter/Dart, Java, Ruby, Rust, Kotlin, PHP, Swift, C#)
- SDK Generator
- Work Task Mode (auto-fix projects)
- Device emulator (iPhone, Android, iPad, Desktop)
- Real terminal, file explorer, code editor
- Git integration
- Package manager (pip)
- 3 build modes: Native, Third-Party, Mixed
- 16 project templates
- Free forever, no account needed

## Requirements

- Windows 10/11
- Python 3.10+
- 500MB disk space

## Optional

- AI Gateway (for AI assistant) - run on port 11436
- Git (for git features)
- Any language compiler you want to build with
